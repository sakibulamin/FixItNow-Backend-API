# 🔧 FixItNow Backend API

A RESTful backend API for a Home Service Marketplace where customers can book technicians, technicians can manage services, and admins can manage the platform.

## 🚀 Features

- JWT Authentication
- Role-Based Authorization
- Customer, Technician & Admin Roles
- Service & Category Management
- Booking Management
- Payment Integration (SSLCommerz)
- Review System
- Global Error Handling

## 🛠️ Tech Stack

- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT
- SSLCommerz

## Roles
- Customer
- Technician
- Admin
